# FontEnum

The text font style that will be used by the application

## Example Usage

```typescript
import { FontEnum } from "crm/models/operations";

let value: FontEnum = "Georgia";

// Open enum: unrecognized values are captured as Unrecognized<string>
```

## Values

```typescript

```
